COMO USAR NO CODE ON THE GO
1. Crie um projeto novo: Java, atividade vazia (Empty/No Activity),
   nome do pacote EXATAMENTE: com.realme.boosterultra
2. No build.gradle do módulo app, confira:
   compileSdk 34 ou maior • minSdk 26 • targetSdk 34 ou 35
3. Apague a pasta app/src/main do projeto novo e coloque no lugar
   a pasta app/src/main deste zip (java + res + AndroidManifest.xml).
   Mantenha os arquivos .gradle do próprio Code on the Go (são as versões que ele tem offline).
4. Compile e instale.

O app não usa nenhuma biblioteca externa: só Java, XML e APIs oficiais do Android.
