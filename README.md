# OMNI C71

App para personalizar o celular inteiro (feito para o realme C71, Android 16), sem root e sem PC.

- **Visual** – tela inicial própria (OMNI Home), cor de destaque, grade, ícones, dock, apps ocultos e papel de parede.
- **Sistema** – brilho, tempo de tela, volumes e, com o Shizuku: animações, DPI (com volta automática em 15s), fonte, tema, Wi‑Fi, Bluetooth, dados, localização.
- **Apps** – congelar/descongelar, remover bloatware para o usuário, restaurar, limpar dados, forçar parada e ligar/desligar permissões.
- **Shizuku** – status, passo a passo sem PC e terminal ADB.

O APK é gerado pelo GitHub Actions em cada push no ramo `omni-c71` e publicado em Releases.
