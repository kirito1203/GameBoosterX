# Dados do Oculto

App de dados 3D para RPG sobrenatural (WebView + WebGL, sem bibliotecas externas).

- `app/src/main/assets/index.html`: o app inteiro
- Dados balanceados: cada número sai uma vez por ciclo e nunca 3 altos ou 3 baixos seguidos

O APK é gerado pelo GitHub Actions e publicado em Releases.
