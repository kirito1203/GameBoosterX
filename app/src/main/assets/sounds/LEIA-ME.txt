PASTA DE SONS EMBUTIDOS — MEME SOUNDBOARD X

Os 241 arquivos .ogg desta pasta são ORIGINAIS: gerados por síntese sonora pelo script
tools/generate_sounds.py (na raiz do projeto). Para regerar:

    python3 tools/generate_sounds.py

O script recria os .ogg e o assets/sounds.json (com duração medida de cada som).

Para adicionar um som embutido manualmente:
1. Coloque o arquivo aqui (preferência: .ogg, mono, 44.1 kHz, até 5 s para tocar sem atraso).
2. Adicione uma entrada em app/src/main/assets/sounds.json, dentro de "sounds":

   {
     "id": "impacto_soco_01",
     "file": "impacto_soco_01.ogg",
     "name": "Soco seco",
     "categoryId": "impactos_comicos",
     "durationMs": 450,
     "license": "CC0",
     "author": "nome do autor",
     "sourceUrl": "https://link-da-origem",
     "tags": ["soco", "impacto"]
   }

Licenças aceitas: CC0, PUBLIC_DOMAIN, CC_BY, ORIGINAL, LICENSED.
Entradas sem licença válida, com categoria inexistente, id repetido ou arquivo ausente
são REJEITADAS e aparecem em Configurações → Biblioteca embutida.

Áudios com direitos autorais (memes de TV, músicas, falas) NÃO devem ser embutidos.
Use a tela "Meus áudios" para importar arquivos do seu celular.
